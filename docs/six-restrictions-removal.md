# 六类附加准入限制移除说明

本独立分支基于 [YuJunZhiXue/dsh-purge](https://github.com/YuJunZhiXue/dsh-purge) 的提交 [`af7cd22d5b3faec540e883239c55bde1620f718a`](https://github.com/YuJunZhiXue/dsh-purge/commit/af7cd22d5b3faec540e883239c55bde1620f718a)。改动对象是插件源代码中作者额外加入的会话与工具准入检查。

本次只修改源码，未安装插件，未对使用者现有客户端应用补丁，也未在真实 Harness 客户端中实测。已完成的隔离验证见下方记录。

## 修改范围

| 类别 | 上游行为 | 本分支行为 |
| --- | --- | --- |
| 公网地址限制 | 按提取到的地址及解析结果限制公网目标，只准入回环或 RFC1918 私网 | 移除该附加地址准入过滤 |
| 未识别目标限制 | 任务命中攻击类关键词且未提取到具体目标时直接拒绝 | 不再因该提取结果为空而拒绝 |
| 强制 DNS 检查 | 准入前解析域名，对解析失败或不符合地址规则的结果拒绝 | 移除准入阶段的强制解析检查；实际网络工具的正常 DNS 行为不受此变更影响 |
| 游戏关键词限制 | 对会话中的游戏相关关键词作额外拒绝判断 | 移除该关键词会话门禁；实际加载的提示词保持不变 |
| 工具参数扫描 | 扫描所有工具参数，按提取出的地址追加准入拒绝，连文件正文中的网址也可能命中 | 移除这层参数扫描门禁；工具本身的参数校验保留 |
| 失效放行名单 | 旧名单接口与“自有服务器”配置容易被误认为仍能决定放行 | 名单不再参与准入；兼容读取与退役写入明确区分 |

这些改动不代表模型保证回答任何问题，也不代表任何工具保证执行成功。模型提供商的规则、宿主权限、工具自身校验和网络条件仍可能影响结果。

## 旧放行名单 API

兼容路径为 `/dsh-purge/own-servers`。

- `GET` 保留只读兼容响应，返回历史文件正文及 `active: false, readOnly: true`；它不把历史名单重新变成准入条件，也不触发迁移或保存。
- `POST` 明确返回 **HTTP 410 Gone** 和 `NET_SCOPE_RETIRED` 错误码。不返回虚假的保存成功，不读取请求正文，也不写入放行名单。
- 历史名单文件不用于决定是否允许一个任务。本次不要求用户补填、登记或更新名单才能继续使用。

调用方应将 HTTP 410 作为接口退役处理，停止显示“保存成功”或要求用户反复重试。这里的兼容接口不用于表达对任何目标的访问授权。

## 保持原状的部分

本次不修改实际加载的提示词、默认人设、规则集、角色稿、回答长度或 token 控制、宿主权限、审批与沙箱逻辑。演练台授权界面、环境适配门禁、评分要求、技能与知识库状态等其他功能也不属于这六类准入检查的修改范围。

实际提示词载荷 `lib/asset-table.js` 保持不变；它没有上述游戏固定拒绝规则。未加载的 `lib/default-prompt-inject.zh.md` 和 `.en.md` 保留上游原文，其中四处游戏禁止只是旧稿残留，不参与当前运行。本分支不发布这些旧稿的修改。源代码移除某条拒绝路径后，模型仍可能受其他文字规则影响。不得把“移除附加代码门禁”描述为“移除了所有限制”。

两份 README 已更新与此分支行为冲突的准入说明。安装教程保留上游内容，未提供或验证此分支的客户端安装流程；既有截图也不是本分支实测截图。

## 验证记录

- **代码确认**：主插件不再挂载网络门禁；整套任务分类、地址提取、DNS 准入及工具扫描实现已删除。旧名单提示拼接和界面闲置加载已清理。实际加密默认提示词、`core.js`、许可与署名文件保持原样。
- **隔离运行确认**：使用 Node 24.19.0 执行真实 `applyHostHooks` 注册路径及其处理器，另用真实 `identity.js` 验证提示词组装，25 项回归测试全部通过。同一套最终测试在上游基线上为 22 项失败、3 项通过，验证测试确实能够捕获旧行为。全部 64 个 JavaScript 文件通过语法检查。
- **覆盖场景**：普通浏览、下载、写入含公网 URL 的文件；无目标理论讨论；明确授权的示例公网地址；域名解析失败或混合地址；游戏关键词；旧工具历史；宿主自身拒绝和工具异常原样传递；旧名单只读与写入退役响应；旧格式提示词去重和普通自定义文本组装。
- **尚未验证**：真实 Harness/Cordis 客户端集成、真实网络下载或文件写入、远端模型回答。测试中的地址、DNS、文件系统及工具执行均为隔离替身，不代表真实公网操作已获准或已经执行。

复现命令及隔离边界见 [tests/README.md](../tests/README.md)。
